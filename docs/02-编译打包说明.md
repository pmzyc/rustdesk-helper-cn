# 02 · 编译打包说明

> 本文说明如何从源码编译出 **RustDesk 一键配置助手** 的单文件 `.exe`，以及背后的若干「坑」与解法。
> 背景：本工具诞生的起因（运营商限制上行 UDP / 443 → 自建 EasyTier 纯 TCP 中继 → 补上官方客户端缺失的开机自启 / 服务常驻 / 注册修复）见 [`01-功能说明.md`](01-功能说明.md)。

---

## 1. 依赖

本工具**只需要 Windows 自带的 .NET Framework 4.x 编译器**，也就是系统里现成的 `csc.exe`：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

- **不需要**安装 Visual Studio。
- **不需要**安装 .NET SDK / `dotnet` CLI。
- 不需要 NuGet 还原任何第三方包：源码只引用系统自带的程序集（`System.Windows.Forms.dll`、`System.Drawing.dll`、`System.Management.dll`、`System.ServiceProcess.dll`）。

只要你的 Windows 装了 .NET Framework 4.x（Win10/Win11 默认自带），就能编译。

---

## 2. 语言限制：只能用 C# 5

上面这个 `csc.exe`（随 .NET Framework 4.0 带的 C# 编译器）**只支持到 C# 5**。因此源码里**不能**使用下列较新的语法：

| 不可用 | 说明 | 替代写法 |
| --- | --- | --- |
| 字符串插值 `$"..."` | C# 6 起 | 用 `"..." + 变量` 拼接 |
| `?.` / `?[]` 空 propagation | C# 6 起 | 显式 `if (x != null)` 判断 |
| 元组 `(a, b)` / `System.ValueTuple` | C# 7 起 | 自定义小类或分开变量 |
| 表达式体成员 `=> expr;`（方法/属性） | C# 6/7 起 | 用完整 `{ return ...; }` 方法体 |
| `nameof(...)` | C# 6 起 | 直接写字符串字面量 |
| `out var` / `is T x` 模式匹配 | C# 7 起 | 先声明变量再 `out 变量` |
| `switch` 表达式、`using` 声明 | C# 8 起 | 传统 `switch` / `using(...)` 块 |

> 改动源码时请务必遵守以上限制，否则编译报「功能不可用 / 需要更高语言版本」之类的错误。

---

## 3. 源码编码：必须 UTF-8 with BOM

- `src\RustDeskHelper.cs` 必须保存为 **UTF-8 with BOM**（带字节序标记）。
- 否则中文（界面文案、提示信息）会**乱码**——因为旧版 `csc.exe` 在缺少 BOM 时会按本地代码页猜测编码。
- 保存后可用十六进制工具确认文件开头是 `EF BB BF`。

---

## 4. 构建脚本：`src\build.ps1` 必须保持纯 ASCII

- `build.ps1` **必须保持纯 ASCII**，一个中文都不能有。
- 原因：**PowerShell 5.1 在解析「无 BOM 的 .ps1」时会按 GBK 解码**，一旦文件里有 UTF-8 中文就会解析失败、脚本直接报错。
- 因此脚本里所有中文（例如产物文件名）都通过 **`[char]0xXXXX` 拼接**出来，而不是直接写中文。例如产物名就是这么拼的：

  ```powershell
  $cnName = 'RustDesk ' + [char]0x4E00 + [char]0x952E + ... + '.exe'
  ```

  对应「RustDesk 一键配置助手.exe」。

> 结论：**改 `build.ps1` 时请勿写入任何非 ASCII 字符**。

---

## 5. 中文路径问题：先在英文临时目录编译

- `csc.exe` 处理**中文路径**会出错（命令行按 ANSI 代码页解释，中文目标路径会被破坏）。
- 所以脚本的做法是：**先在纯英文的临时目录编译，再把产物复制到中文目标路径**。
- 临时目录固定为：`%TEMP%\rdhelper_build`（纯英文、稳妥）。脚本会：

  1. 把源码复制为 `%TEMP%\rdhelper_build\src.cs`；
  2. 在那里编译输出 `out.exe`；
  3. 再把 `out.exe` 复制到仓库**上一级**目录，命名为中文产物名。

---

## 6. 图标：从 `rustdesk.exe` 原样提取

为了和官方图标**完全一致**，脚本不自己画图标，而是从已安装的 `rustdesk.exe` 里**原样提取**：

- 用 `LoadLibraryEx`（`LOAD_LIBRARY_AS_DATAFILE | LOAD_LIBRARY_AS_IMAGE_RESOURCE`）以资源方式加载 exe；
- 用 `FindResource` / `EnumResourceNames` / `LoadResource` / `SizeofResource` 枚举并读取 **`RT_GROUP_ICON`** 与 **`RT_ICON`** 资源；
- 把提取到的原始图标位图**重建为标准 `.ico` 文件**（脚本会挑选带 256×256 帧的那一组，通常是应用主图标）；
- 再用 `/win32icon:rustdesk.ico` 传给 `csc` 编译进产物。

因此产物的图标与官方 `rustdesk.exe` 逐字节一致。脚本会自动在注册表 `Uninstall\RustDesk` 与常见安装路径里寻找 `rustdesk.exe`；找不到时退回默认图标并给出警告。

---

## 7. 编译命令与产物

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File src\build.ps1
```

产物输出到**仓库目录的上一级**：

```
RustDesk 一键配置助手.exe     （约 47 KB）
```

脚本最后会打印 `[done] ... (xxxxx bytes)` 说明产物大小。

> 若构建脚本报路径或权限问题，确认：`src\RustDeskHelper.cs` 是 UTF-8 with BOM、`build.ps1` 纯 ASCII、以及你对仓库上一级目录有写权限。

## 8. 自定义（自改自用）

### 8.1 改图标

- **推荐做法**：不动脚本。只要安装一个官方 `rustdesk.exe`，脚本会自动提取它的图标——换个版本的 RustDesk，图标也随之变化。
- 想用**自己的图标**：准备一个标准 `.ico`，把脚本里 `/win32icon:` 指向你的文件即可；或直接替换 `%TEMP%\rdhelper_build\rustdesk.ico` 后跳过提取步骤。

### 8.2 改作者信息

- 界面右下角「作者：九头鱼　pmzyc@qq.com」等文案在 `src\RustDeskHelper.cs` 里。
- 直接搜索该字符串替换即可（注意保存为 **UTF-8 with BOM**）。

### 8.3 改默认服务器

- 源码顶部有一组常量：

  ```csharp
  public const string DefServer = "";   // 默认 ID 服务器
  public const string DefKey    = "";   // 默认 Key
  public const string DefApi    = "";   // 默认 API（一般留空）
  ```

- 本**公开版**把它们全部留空——**不内置任何私人服务器信息**，首次使用需在界面【服务器设置】里手填。
- 如果你要发布自己的分支并想预置默认值，就在这里填写；但**强烈不建议把真实 Key / 域名提交到公开仓库**（见 [`04-EasyTier纯TCP中继服务器说明.md`](04-EasyTier纯TCP中继服务器说明.md) 的安全提示）。

## 9. 编译流程小结

```
src\RustDeskHelper.cs (UTF-8 with BOM)
        │  csc.exe (C# 5, Framework64\v4.0.30319)
        │  /target:winexe /optimize+
        │  /reference:System.{Windows.Forms,Drawing,Management,ServiceProcess}.dll
        │  /win32icon: (从 rustdesk.exe 提取的官方图标)
        ▼
%TEMP%\rdhelper_build\out.exe  ──复制──▶  RustDesk 一键配置助手.exe (~47 KB)
```
