# 01 · 功能说明

> 本文详述 **RustDesk 一键配置助手**（以下简称「本工具」）的界面结构、全部功能与设计取舍，以及它**为什么会被做出来**。
> 本工具本身**不实现远程控制**，也不修改 RustDesk 原生程序文件，只是一个把 RustDesk 常用设置与排障动作收纳到一个中文面板里的「外挂助手」。

---

## 1. 为什么会有这个工具（背景故事）

本工具的作者所在宽带被运营商（联通）**限制了上行 UDP 与 HTTPS(443) 流量**。后果是：

- RustDesk 的**官方服务器连不上**；
- 客户端之间的 **P2P 打洞也打不通**（打洞高度依赖 UDP）。

于是作者自建了一套 **EasyTier 去中心化组网**，并把它配置成**纯 TCP 中继**模式（只走运营商没封的 TCP 端口），把所有机器拉进同一个虚拟局域网（虚拟 IP 网段，例如 `10.0.0.0/24` 这类自定网段）；随后把 **RustDesk 服务端（`hbbs` / `hbbr`）部署在这个虚拟局域网内部**，客户端把 **ID 服务器 / 中继服务器**都指向它。这样即使 UDP 与 443 被封，也能通过 TCP 中继稳定地远程。

网络问题解决后，官方 RustDesk 客户端本身又暴露出三个「坑」，逼出了本工具：

1. **不会开机自启动**：机器重启后必须人工打开客户端，远程就断了；官方也没有一个可靠的设置入口把这几个动作固化下来。
2. **停在 Windows 登录界面时无法被远程**：没登录桌面（还停在登录界面）时，RustDesk 客户端进程根本不会以能接收连接的形态跑起来——需要让 RustDesk 以**服务方式常驻**，才能真正做到「开机即可远程」。
3. **经常注册不上 / 状态卡住**：需要人工重置注册状态、重写服务器配置、重启客户端才能恢复。

本工具就是把这三点，以及日常用到的 ID / 密码 / 配置 / 日志操作，集中到一个**单文件、秒开、全中文**的小面板里。EasyTier 相关的组网做法详见 [`04-EasyTier纯TCP中继服务器说明.md`](04-EasyTier纯TCP中继服务器说明.md)。

## 2. 程序形态

- **语言 / 框架**：C# / WinForms，单文件源码。
- **编译产物**：约 **47 KB** 单个 `.exe`。
- **启动速度**：约 **130~200 毫秒**，面板「先显示、后刷新」。
- **图标**：直接复用本机 `rustdesk.exe` 的官方图标（与官方完全一致）。
- **前提**：已安装官方 RustDesk **1.5.x**；本工具不改动原生程序文件。

> 编译方法见 [`02-编译打包说明.md`](02-编译打包说明.md)。

## 3. 界面结构

打开后是一个全中文窗口（可参考仓库内截图 `docs/images/screenshot-main.png`）：

### 3.1 顶部标题栏

蓝色标题栏，**右上角一个状态胶囊**，根据实时状态显示：

- `已连接 <服务器>` —— 已成功注册到所填服务器；
- `注册中… <服务器>` —— 正在注册；
- `客户端未运行` —— 客户端进程没跑起来。

### 3.2 两个标签页

顶部有两个标签：**【连接状态】** 与 **【服务器设置】**；窗口内按卡片分区，配合 `?` 图标提供行内帮助。

---

### 3.3 【连接状态】页

包含以下卡片：

**① 设备 ID**

- 只读显示本机 RustDesk ID，带【复制】按钮。

**② 固定密码**

- 默认以圆点掩码显示；密码框内的「小眼睛」图标可切换明文/掩码。
- 带【复制】【设置】按钮；未设置时框内显示提示文字（引导你去设置）。
- 设置走官方命令 `rustdesk.exe --password "xxx"`，**立即生效、无需重启**。
- 注意：**绝不会**把 `password` 写进 `RustDesk.toml` 的 `[options]` 段（原因见第 4.4 节）。

**③ 开机自启动**

- 两个复选框：
  - `登录 Windows 后自动启动`
  - `开机即启动（服务器，需管理员）`
- 每项右侧**实时回显**状态：`✓ 已设置`（绿）或 `✗ 未设置`（红）。
- 带【保存】按钮，保存后按计划任务真实存在情况回刷。

**④ 客户端状态**

- 同一行显示两组状态：
  - `客户端进程 ● 运行中 / 未运行`
  - `与服务器连接 ● 已连接 / 未连接`
- 右侧是 【启动】/【停止】 和 【连接】/【断开】 两组按钮。
- 卡片右上角显示本机 RustDesk 版本号（例如 `1.5.0+68`）。
- 附 `?` 帮助，专门说明「客户端进程」与「与服务器的连接」**是两回事**（见第 4.1 节）。

**⑤ 四个动作按钮**

**【打开客户端】【修复连接】【配置目录】【查看日志】**

**⑥ 底部状态行**

- 形如：`客户端：… ｜ 与服务器连接：… ｜ 服务器密钥：…`
- 正常项为**绿色**、异常项为**红色**。
- 左下角显示管理员状态：`当前以管理员身份运行` / `未以管理员身份运行，部分功能受限`。
- 右下角显示作者信息：`作者：九头鱼　pmzyc@qq.com`。

---

### 3.4 【服务器设置】页

- 三个输入框：**ID 服务器**、**中继服务器**、**Key**，外加【同步到客户端】按钮。
- 带 `?` 帮助说明各字段含义。
- 三大字段含义（帮助里也写清楚了）：
  - **ID 服务器**：`hbbs` 的地址，例如 `192.168.1.10` 或 `你的域名`。
  - **中继服务器**：`hbbr` 的地址；留空则与 ID 服务器相同。
  - **Key**：必须与服务端 `id_ed25519.pub` 文件内容**完全一致**，否则客户端永远注册不上。
- 填好后点【同步到客户端】，再点【修复连接】让它重新注册。

> 本工具**不内置任何服务器地址**（公开版把地址、Key、API 全部留空）。首次使用必须自己填写。

## 4. 功能清单（v5.1）

### 4.1 区分并独立控制两类状态

RustDesk 运行时由几类进程组成，必须分清，否则「客户端进程」的启停判断会出错：

| 进程形态 | 说明 | 结束它 |
| --- | --- | --- |
| `rustdesk.exe --service` | 服务宿主进程（由 Windows 服务托管） | 不能随意结束 |
| `rustdesk.exe --server` | 由服务**自动拉起的子进程** | **会立刻重生** |
| 其他进程（含 `rustdesk.exe --tray`） | 真正的「客户端进程」 | **不会重生** |

- 本工具只把**第三类**算作「客户端进程」。早先版本把 `--server` 也算了进去，导致状态永远显示「运行中」、点【停止】后按钮不会变回【启动】。
- 「与服务器的连接」对应的是 Windows 服务 `RustDesk`（`--server` 子进程由它自动拉起）。**服务在跑 ≠ 客户端进程在跑**，这是两个独立状态。

### 4.2 开机自启动（计划任务）

- 写入两个 Windows 计划任务：
  - `RustDeskHelper` —— 登录后启动（`ONLOGON`）。
  - `RustDeskHelper-Boot` —— 开机即启动（`ONSTART`，以 `SYSTEM` 运行，**需管理员权限**）。
- 保存后**实时回显**是否已设置。

### 4.3 服务器配置一键写入

- 写入 `%APPDATA%\RustDesk\config\RustDesk.toml` 与 `RustDesk2.toml`。
- 字段：`custom-rendezvous-server`、`relay-server`、`key`、`disable-udp`、`allow-websocket`、`enable-lan-discovery`、`direct-access-port`。
- 各字段含义与取舍见 [`03-局域网使用说明.md`](03-局域网使用说明.md)。

### 4.4 固定密码设置

- 调用官方命令 `rustdesk.exe --password "xxx"` 写入客户端，**立即生效、无需重启**。
- **绝不能**把 password 写进 `[options]` 段——RustDesk 不识别，这是「固定密码不生效」的常见原因。
- 本工具会自动**清理**配置里遗留的无效 `password` 项。

### 4.5 一键修复连接

流程：

1. 备份配置（`RustDesk.toml` → 追加时间戳后缀的 `.bak-*`）。
2. 重置注册状态：把 `key_confirmed`（及相关条目）由 `true` 改为 `false`。
3. 重写服务器配置。
4. 重启客户端。
5. 后台轮询校验是否重新注册成功。

> 全程**不删除任何系统目录**。

### 4.6 实时状态刷新

- 后台线程每 **1.5 秒**轮询一次，界面不卡；面板先显示、再异步刷新，所以打开即可见、随后状态逐项点亮。

### 4.7 未安装 RustDesk 时自动下载安装

- 打开工具若未检测到已安装的 RustDesk，会**弹窗询问**是否自动下载安装当前最新版。
- 流程：GitHub API 取最新 `x86_64` 安装包 → 带进度窗口下载 → 以 `--silent-install` **提权静默安装** → 最长**轮询 4 分钟**等待安装完成（客户端出现即视为完成）。
- 静默安装会触发「用户账户控制」，请选「是」。

### 4.8 其它

- 全中文界面、单文件、秒开。
- 图标直接复用本机 `rustdesk.exe` 的官方图标。

---

## 5. 与 RustDesk 的边界（重要）

- 本工具**不实现远程控制**：真实的远程画面传输、编解码、输入注入等都由官方 RustDesk 完成。
- 本工具**不修改** RustDesk 原生程序文件（不 patch、不替换 exe、不改 DLL）。
- 本工具只做三件事：**读/写 RustDesk 的配置与注册状态**、**启停客户端进程**、**登记开机自启动计划任务**。
